Monkeytyper

Two Python scripts that open Monkeytype in Chrome and type the test for you. One reads the words straight from the page, the other reads a screenshot with OCR and presses real keys.

Step-by-step setup Source on GitHub

Educational use only, play fair

These scripts exist to demonstrate web automation, computer vision (CV), OCR and DOM interaction. Do not use them to compete on public leaderboards, fake benchmark scores, or disrupt typing communities. Automating a third-party site may break its Terms of Service, and you could lose your account. You use them at your own risk.

What is it?

Monkeytyper is a pair of small Python programs for Monkeytype. Each one launches Chrome with Selenium, finds the words on the screen, and types them. They show two very different ways to solve the same problem:

  • DOM method (dom_selenium.py): asks the page for the exact word it needs and sends it straight into Monkeytype's input box.
  • OCR method (ocr_pyautogui.py): takes a screenshot, cleans it up with OpenCV, reads it with Tesseract OCR, then presses real keys with PyAutoGUI.

Short version: start with the DOM method, since it is simpler to install and more accurate. Pick the OCR method if you want to learn how a screenshot-to-keystroke pipeline works.

How each one works

DOM method

  1. Persistent session. Chrome starts with a local profile folder (selenium_chrome_profile), so cookies and settings are remembered.
  2. Read the word. A snippet of JavaScript looks for the active word in #words (or the first untyped one) and returns its text.
  3. Type the word. The text plus a space is sent to the #wordsInput element.
  4. Repeat. It waits 0.05 s and loops until no words are left.

OCR method

  1. Open the page. Chrome loads Monkeytype and the script waits 5 seconds for you to handle cookies.
  2. Capture. It clicks the words area and saves a screenshot of #wordsWrapper.
  3. Clean up. OpenCV upscales the image 2x, makes it grayscale and applies a threshold so the letters stand out.
  4. Read. Tesseract (--psm 6) turns the image into text, which is printed in the console.
  5. Type. PyAutoGUI presses each character with a 0.015 s delay, then the browser closes after 5 seconds.

Setup: step by step

You need Google Chrome and Python 3 on your computer. The OCR method is written for Windows paths, so the DOM method is the easier first run.

  1. 1

    Install Python and Chrome

    1. Install Python 3. On Windows, tick Add python.exe to PATH in the installer.
    2. Make sure Google Chrome is installed and up to date.
    3. Check Python works by running this in a terminal:
    python --version
  2. 2

    Get the scripts

    Download the monkeytype project from my GitHub and unzip it, then open a terminal inside that folder. It contains dom_selenium.py and ocr_pyautogui.py.

  3. 3

    Install what your method needs

    Install the two packages:

    pip install selenium webdriver-manager

    That is all. WebDriver Manager downloads a matching ChromeDriver automatically the first time you run it.

    A. Install the Python packages:

    pip install selenium webdriver-manager opencv-python pytesseract pyautogui

    B. Install the Tesseract OCR engine. On Windows, download the installer (for example the UB-Mannheim build) and note where it installs.

    C. Point the script at Tesseract. Open ocr_pyautogui.py and edit this line near the top so it matches your install location and username:

    pytesseract.pytesseract.tesseract_cmd = r"C:\Users\<YourUsername>\AppData\Local\Tesseract-OCR\tesseract.exe"

    The file currently points at the author's folder, so it will fail on your machine until you change it.

  4. 4

    Run it

    In your terminal, run the script for the method you chose:

    python dom_selenium.py
python ocr_pyautogui.py

    (Run only one of them.) Here is what you will see:

    1. A maximized Chrome window opens on monkeytype.com.
    2. The console says Waiting 5 seconds…. Use that time to accept the cookie popup and choose your test settings.
    3. DOM method: it starts typing word by word and stops when the words run out. Chrome stays open afterwards.
    4. OCR method: it saves monkeytype_words.png and processed_words.png, prints the text it read, types it, then closes Chrome after 5 seconds. It only types the words visible on screen at that moment.
  5. 5

    Tips while it runs

    • OCR method: keep the Chrome window focused and do not touch the keyboard. The keystrokes go to whichever window is active.
    • OCR method: to abort, slam the mouse into a screen corner. That triggers PyAutoGUI's built-in fail-safe.
    • DOM method: press Ctrl + C in the terminal to stop it.
    • DOM method: the saved profile can keep you logged in to Monkeytype, so results may be recorded on your account. Please read the fair-play note at the top.

Troubleshooting

ModuleNotFoundError (selenium, cv2, pyautogui…)

A package is missing. Re-run the pip install line for your method from step 3, and make sure you use the same Python that runs the script.

TesseractNotFoundError (OCR method)

Tesseract is not installed, or the path in ocr_pyautogui.py is wrong. Install it, then update the tesseract_cmd line to the real location of tesseract.exe.

NoSuchElementException (can't find wordsInput or wordsWrapper)

The page was not ready yet, a popup was in the way, or Monkeytype changed its layout. Increase the time.sleep(5) near the top and accept any popups first.

The DOM method depends on specific IDs and classes, so a site update can break it until the selectors are changed.

ChromeDriver or browser version errors

Update Google Chrome and upgrade the helper with pip install -U selenium webdriver-manager. WebDriver Manager needs an internet connection the first time to fetch the driver.

The OCR text has mistakes

Accuracy is roughly 90 to 98% and depends on how clean the screenshot is. Try a larger browser zoom or a theme with higher contrast. For perfect text, use the DOM method.

Typing lands in the wrong window (OCR method)

PyAutoGUI sends real OS keystrokes. If you click away from Chrome during the run, the characters go to whatever you clicked. Leave the Chrome window in front until it finishes.
