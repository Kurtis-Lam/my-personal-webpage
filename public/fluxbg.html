fluxbg

An Android wallpaper app built for Huawei phones. Add a static image or a dynamic video from your gallery, crop it, trim videos on a video-editor style timeline, and use it as your home screen and/or lock screen wallpaper.

Get the APK Source on GitHub

What is it?

fluxbg lets you use your own videos and animations as a live wallpaper, something Huawei's stock tools make hard. Pick a clip, frame it with the crop window, trim the part you want, and apply it to the home screen, the lock screen, or both.

It is designed for Huawei phones (EMUI 8+ and the HarmonyOS versions that run Android APKs, HarmonyOS 2 to 4.x). It targets Android 8.0+ (API 26) and works on all Huawei phone lines: Pura, Mate, nova, P, Y and the foldables. It should also work on other Android devices.

Features

  • Home screen is My library, with Images and Videos buttons to switch between everything you have added.
  • Add wallpaper asks for Static (upload an image) or Dynamic (pick a video), then goes straight to the editor.
  • Crop with a fixed-aspect window matched to your screen: drag the sides or corners to resize, drag inside to move, or pinch.
  • Trim videos on a timeline bar with a thumbnail strip, draggable in/out handles and a scrub playhead. Long videos show 10 seconds at a time and the timeline scrolls sideways.
  • Preview playback that loops only the trimmed range.
  • Separate settings for the home screen, the lock screen, or both.
  • Applying always asks before overwriting your current wallpaper, then returns you to the library.
  • Static images are set directly, with no system preview.
  • Lock screen option that sets the frame at the playhead (or the cropped image), checks that the phone really changed it, and falls back to the system Set as sheet.
  • Asks for storage access when the fallback needs it (Android 9 and older).
  • Crop adapts automatically to each screen's aspect ratio, including foldables.
  • Muted, GPU-rendered playback that pauses when the screen is off to save battery.

How to use it

Install the APK (from Releases or built yourself), open fluxbg, then follow these steps.

  1. 1

    Add a wallpaper

    Tap Add wallpaper and choose Static to upload an image or Dynamic to pick a video. Or open My library, use Images / Videos to switch, and tap an item you added earlier. Hold an item to delete it.

  2. 2

    Crop it

    In the editor, drag the sides or corners of the crop window (or pinch) to frame the shot, and drag inside it to move it.

  3. 3

    Trim videos

    Drag the handles on the timeline to set the in and out points, tap the bar to seek, and swipe the timeline to scroll through long clips. Tap the play button to preview the loop.

  4. 4

    Choose where it goes

    Under Apply to, choose Home screen, Lock screen or Both, then tap the main button. fluxbg warns that it will overwrite your current wallpaper. Confirm to apply and return to the library.

  5. 5

    Confirm the preview

    • Images are applied immediately.
    • Dynamic videos open the system live wallpaper preview. Confirm it there.
    • For the lock screen, the main button sets a still picture (the frame at the playhead for videos). If your phone does not confirm the change, fluxbg offers the system Set as sheet so you can pick Lock screen. Try live video on lock screen opens the live wallpaper preview instead.

    To change the file, crop or range later, open it from the library and apply it again.

Build from source

You need Android Studio, JDK 17 or newer and Android SDK Platform 34.

  1. 1

    Clone and open

    Clone the repo and open it in Android Studio, then let Gradle sync.

    git clone https://github.com/Kurtis-Lam/fluxbg.git
  2. 2

    Build the APK

    Choose Build > Build APK(s). The APK is written to:

    app/build/outputs/apk/debug/app-debug.apk
  3. 3

    If the Kotlin compiler daemon crashes

    Add this to gradle.properties:

    kotlin.compiler.execution.strategy=in-process
org.gradle.jvmargs=-Xmx2048m

    Also keep the project outside cloud-synced folders (Synology Drive, iCloud, Dropbox), which can lock build files.

Known limitations

Live lock screen support varies by EMUI / HarmonyOS version

Huawei's Themes app may override third-party live wallpapers on the lock screen. Separate home and lock videos need Android 14 level support (HarmonyOS 4.2 and later). On older systems the lock screen uses the home screen settings.

HarmonyOS NEXT (5.0 and later) is not supported

HarmonyOS NEXT does not run Android APKs, so fluxbg cannot be installed on it.

A brief hitch at the loop point

Looping uses MediaPlayer seeking, so there may be a short hitch where the clip restarts, especially with long keyframe intervals. Re-encoding the clip with frequent keyframes helps.

Very high-resolution or long videos

They use more battery and storage. Selected videos and images are copied into the app's private storage.

HTML-based animated backgrounds

Not supported yet.

The released APK may be out of date

The APK on the Releases page may be older than the current source code. Build from source for the latest changes.
