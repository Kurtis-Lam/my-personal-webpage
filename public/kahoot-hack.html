Kahoot Hack

A Chrome extension that reads the question on a Kahoot! game, asks an AI model for the answer through OpenRouter, then highlights it and can click it for you.

Step-by-step setup Source on GitHub

Read this first

This project is for educational purposes only. Using automated tools on Kahoot! likely breaks its Terms of Service and can get your account or game session banned. Only try it in games you host yourself, or where everyone playing has agreed to it, and never in graded or competitive games. You use it at your own risk.

What is it?

Kahoot Hack is a Manifest V3 Chrome extension that runs on kahoot.it. When a question starts, it grabs the question and the answer options, sends them to an AI model through OpenRouter, and shows you what the AI picked.

There is no sign-in, no account and no usage limit on the extension itself. You bring your own OpenRouter API key, so you control the cost and nobody else sees your usage.

Features

AI-powered answers

Sends each question to a vision-capable model through OpenRouter, so image questions can work too.

Multiple keys, auto failover

If one key fails or is rate-limited, the next key in your list is used automatically.

Highlight the answer

Draws a ✅ on the option the AI chose, so you can check it yourself.

Optional auto-click

Clicks the answer through the page, with a WebSocket fallback if the normal click does not register.

Delay slider

Wait 0 to 10 seconds before auto-clicking. A countdown shows, and you can cancel it with a click.

Reconnect handling

If the connection drops mid-question, your pending answer is sent again (up to 2 times).

How it works

  1. 1

    It detects the question

    A small script is injected into the Kahoot page and picks up the question text and its answer choices as the round begins.

  2. 2

    It asks the AI

    The extension's background worker sends them to OpenRouter, trying your keys one after another until one works.

  3. 3

    It shows the answer

    The status line moves from Resolving answer... to Highlighting answer... and a ✅ appears on the chosen option.

  4. 4

    It can click for you

    With auto-click on, it waits your chosen delay and then submits the answer. Turn it off to just see the highlight.

Setup: step by step

Takes about 10 minutes. You need Google Chrome (or Edge, Brave, Opera), an OpenRouter account, and a Kahoot! game to join.

  1. 1

    Get the extension folder

    Download the kahoot-hack folder from my GitHub and unzip it somewhere permanent (Chrome loads it from that location, so do not delete it afterwards).

    It should look like this once you have added your keys file in step 3:

    kahoot-hack/
├── manifest.json
├── background.js
├── content.js
├── keys.json          <- you create this
└── scripts/
    └── injected.js

    Important: keys.json must sit in the root of the folder, right next to manifest.json.

  2. 2

    Create an OpenRouter API key

    1. Go to openrouter.ai and click Sign In (top right). Google, GitHub or email all work.
    2. Open the keys page: openrouter.ai/keys (or click your avatar, then Keys).
    3. Click Create Key, name it something like kahoot-hack, then click Create.
    4. Copy the key immediately. It starts with sk-or-v1- and is only shown once, so store it somewhere safe.
    5. Recommended: open Credits in the left sidebar and add a few dollars. Free models exist, but paid ones are more reliable, and vision models are cheap per request.
    6. Optional: repeat steps 3 and 4 to make more keys. The extension rotates through all of them if one fails.
  3. 3

    Put your key(s) in keys.json

    In the extension folder, create a file named keys.json and paste this, replacing the placeholders with your own keys:

    {
  "API_KEYS": [
    "sk-or-v1-YOUR-FIRST-KEY-HERE",
    "sk-or-v1-YOUR-SECOND-KEY-HERE"
  ]
}
    • It must be valid JSON: double quotes only and no trailing commas.
    • The array must be named exactly API_KEYS.
    • One key is enough. More keys means more protection against rate limits.
    • Never share this file or upload it to GitHub. Anyone with a key can spend your credits.
  4. 4

    Load the extension in Chrome

    1. Open a new tab and go to chrome://extensions
    2. Turn on Developer mode (top-right corner).
    3. Click Load unpacked (top-left).
    4. Select the folder that contains manifest.json, which is the root of kahoot-hack/, not the scripts folder.
    5. Kahoot Hack now appears in the list. Make sure its toggle is ON.

    Changed a file later? Click the ↻ refresh icon on the Kahoot Hack card, then reload any open Kahoot tabs.

  5. 5

    Use it

    1. Go to kahoot.it and join a game with its PIN as usual.
    2. When a question starts, the ⚡ kahoothack panel shows up in the top-right corner.
    3. Watch the status line: Question detected → Resolving answer... → Question sent → Highlighting answer...
    4. The ✅ appears on the answer the AI picked. With auto-click on, it also selects it after your delay.
    5. The AI can be wrong, especially on image-only questions, so treat the highlight as a suggestion.

Troubleshooting

"No API keys found…"

Make sure keys.json exists in the root of the extension folder, next to manifest.json.

Check that the JSON is valid (paste it into jsonlint.com), then click the ↻ refresh icon on chrome://extensions.

"All N API keys failed"

Open chrome://extensions → Kahoot Hack → Service worker → Inspect. The errors appear in the Console.

Common causes are an invalid key, no credits left, or a model that is not available on your account. Adding more keys to keys.json spreads the requests out.

The panel doesn't appear

Check that the extension's toggle is ON, then reload the Kahoot tab.

Incognito mode may be enabled. Open the pill to turn it off, or clear the silentMode value from chrome.storage.

The answer is wrong

The AI can be wrong, especially on image-only questions. You can try a different model by editing the MODEL constant in background.js, then refreshing the extension.

Answers aren't submitted after a reconnect

The injected script keeps a pending answer in sessionStorage and resends it up to 2 times. If it gives up, rejoin the game.

Security & privacy

  • Your keys live only in keys.json inside the extension and are sent nowhere except OpenRouter.
  • The Kahoot question text is sent to OpenRouter to get an answer. Do not use this if you are not comfortable with that.
  • Never publish or share the folder while keys.json holds real keys.
